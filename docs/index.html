Touch ID for Hackintosh

Fingerprint authentication for macOS on unsupported hardware. Unlock with a real fingerprint sensor instead of typing your password.

Get startedDocumentationGitHub

What is it?

HTID is a fingerprint authentication daemon for macOS on Hackintosh hardware. It ports the USB capture protocol of supported fingerprint sensors to native C, matches swipes with NIST's NBIS suite, and types your password into the macOS prompt when your finger matches. It is not a kernel extension and not a libfprint port.

Built for laptops that shipped with a fingerprint sensor but have no native macOS driver.

Features

Lock screen

Unlock with a fingerprint swipe.

Authentication prompts

System Settings padlock, Finder, Passwords.app and Keychain Access consent prompts.

Multi-finger enrollment

Enroll several fingers, best match wins.

Fully native

No kernel extension and no libfprint at runtime. A small background daemon.

Encrypted storage

Templates and the stored password live on a dedicated encrypted APFS volume.

Menu bar app

Optional app to enable, disable or restart the daemon, with notifications when it is ready to swipe.

Supported macOS

VersionStatus
macOS 15 Sequoia and laterRecommended
macOS 14 SonomaSupported (minimum)
macOS 13 Ventura and olderNo support. It may work, but you are on your own.

OpenCore v1.0.6 or later is required for support. Release or Debug builds are both fine. Older versions may work but are not supported.
